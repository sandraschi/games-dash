# Games MCP Server (gameops) Overview

The Games MCP server provides a comprehensive orchestration and analysis platform for traditional tabletop games, specifically optimized for correspondence play and advanced learning.

## Key Domains

- **Move Recording & Correspondence Play**: Tools for tracking games played on physical boards or across various platforms.
- **AI-Powered Analysis**: Deep engine integration with Stockfish (Chess), Shogi-server, and Katago (Go).
- **Intelligent Orchestration (SEP-1577)**: Advanced AI workflows that use sampling to autonomously manage complex analysis and coaching.
- **Persistence & Integration**: Full integration with Advanced Memory (ADN) for saving analysis notes and SQLite for game state persistence.

## Help Topics

Use the `help(topic="...")` tool to dive deeper into specific areas:

- `game_ops`: Move recording, state management, and correspondence play.
- `analysis`: AI engine parameters, evaluation metrics, and system status.
- `sampling`: Details on intelligent orchestration and autonomous learning.
- `persistence`: Database management and ADN integration.
- `tournaments`: Competitive play and rating system details.

## Core Philosophy

Following Sandra's materialist and reductionist philosophy, the Games MCP server treats game states as the ultimate substrate of reality. Every move is a data point, and every analysis is an empirical verification of tactical and strategic truth.

# Japanese Learning Suite

Kanji, vocabulary, JLPT practice, grammar, and listening — all in your browser.

## Tools

| Tool | Description |
|------|-------------|
| Kanji Wall | Browse 2,500 kanji by JLPT level, grade, radical, stroke count |
| Kanji Master | Reading and meaning practice with spaced repetition |
| JLPT Practice Test | Full N5-N1 format practice (database-driven) |
| JLPT Vocabulary | Master JLPT words by level |
| Japanese Grammar | Pattern recognition games |
| Japanese Flashcards | Spaced repetition vocabulary (600+ cards) |
| Japanese Listening | Text-to-speech listening practice |
| Stroke Order | Learn to write kanji with stroke animation |
| Hiragana/Katakana | Master both Japanese scripts |
| Kanji Table | Complete kanji reference database |

## Cultural

## JLPT Levels

| Level | Kanji | Vocabulary | Description |
|-------|-------|------------|-------------|
| N5 | ~100 | ~800 | Basic |
| N4 | ~300 | ~1,500 | Elementary |
| N3 | ~650 | ~3,750 | Intermediate |
| N2 | ~1,000 | ~6,000 | Pre-advanced |
| N1 | ~2,000 | ~10,000 | Advanced |

## How to Use

Start the gateway and open the Japanese Language section:

```powershell
.\start.ps1
# Opens http://localhost:10987/
# Click "Japanese Learning Games" category
```

Or jump directly to:
- Kanji wall: http://localhost:10987/games/Japanese%20Language/kanji-table.html
- JLPT practice: http://localhost:10987/games/Japanese%20Language/jlpt-practice-test.html
- Flashcards: http://localhost:10987/games/Japanese%20Language/japanese-flashcards.html

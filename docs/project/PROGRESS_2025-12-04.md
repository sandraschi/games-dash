### Unified Multiplayer System

**NEW: Automatic Local/Internet Detection:**
- **NEW:** `unified-multiplayer.js` - Smart client that auto-detects connection type
- **NEW:** `unified-multiplayer-demo.html` - Demo showing the unified system
- **Features:**
  - Automatic mode detection (WebSocket for local, Firebase for internet)
  - Seamless fallback from local to internet play
  - Reconnection handling with exponential backoff
  - Game state synchronization across both modes
  - Chat support in both local and internet modes

**Connection Logic:**
1. **Try WebSocket first** (local network - same WiFi)
   - Attempts: `ws://localhost:9877`, `ws://127.0.0.1:9877`, `ws://hostname:9877`
   - Timeout: 2 seconds per attempt
2. **Fallback to Firebase** (internet play - different locations)
   - Uses existing Firebase config if available
   - Works anywhere with internet connection
3. **Automatic reconnection** if connection lost
   - Up to 3 attempts with exponential backoff
   - Switches modes if needed

**Benefits:**
- ✅ **No manual configuration** - automatically chooses best connection
- ✅ **Works locally AND remotely** - plays with Steve in Hollabrunn
- ✅ **Seamless experience** - no user intervention needed
- ✅ **Backward compatible** - existing Firebase games still work
- ✅ **Smart reconnection** - handles network changes gracefully

**Usage:**
```javascript
// Just include the script - it auto-initializes
<script src="unified-multiplayer.js"></script>

// The system automatically:
// 1. Tries local WebSocket connection
// 2. Falls back to Firebase if local fails
// 3. Reconnects automatically if connection drops
```

## Important Note: Multiplayer Limitations

**WebSocket Server Limitation:**
- The WebSocket server (`multiplayer-server.py`) only works for **local network play**
- Players must be on the same WiFi/LAN
- **Does NOT work for internet play** (players in different locations)

**For Internet Play:**
- Use **Firebase** instead (see `FIREBASE_SETUP_GUIDE.md`)
- Firebase was chosen specifically to solve the "different locations" problem
- Free tier is sufficient for personal use
- See `MULTIPLAYER_OPTIONS.md` for detailed comparison

# 👥 User Guides

Welcome! These guides are written for everyone - whether you're a gamer, teacher, parent, or just curious about this games collection. No technical knowledge required!

## 🎯 Quick Start for Gamers

### Just Want to Play? Here's How:

1. **Download**: Get the games from [GitHub Releases](../../releases)
2. **Install**: Double-click `Install_Games.bat` (Windows only)
3. **Play**: Open your browser to `http://localhost:9876`

That's it! The installer handles everything automatically.

### What You'll Get:
- **75 Games** from simple puzzles to professional chess
- **AI Opponents** that play like experts
- **Multiplayer** for playing with friends
- **Mobile Support** works great on iPad and phones

## 🔧 Getting Help

### Common Issues & Solutions

**Games Won't Load:**
- Make sure all servers are running (check the installer)
- Try refreshing your browser
- Check if antivirus is blocking the servers

**AI Not Working:**
- AI engines need to run on Windows
- For remote play, use the remote setup guide
- Check the connectivity test page

**Slow Performance:**
- Close other programs
- Try a different browser
- For mobile, ensure good WiFi connection

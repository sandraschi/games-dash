# 🎮 Gamer's Quick Start Guide

**Get playing in under 5 minutes!** This guide is for anyone who wants to play games without technical setup.

## ⚡ Quick Setup (2 Minutes)

### Step 1: Download
- Go to [GitHub Releases](../../releases)
- Download the latest `.zip` file
- Extract to any folder (Desktop recommended)

### Step 2: Install
- **Windows**: Double-click `Install_Games.bat`
- **Wait**: The installer handles everything automatically
- **Done**: When you see "Installation complete!"

### Step 3: Play
- Open your browser (Chrome, Firefox, or Edge)
- Go to: `http://localhost:9876`
- **Start playing any of 75 games!**

## 🌍 Playing from Different Devices

### On Your Computer
- **Already set up!** Just use `http://localhost:9876`
- **Full features**: All games, AI opponents, achievements
- **Best performance**: Local computer for fastest gameplay

### On iPad/Phone (Same WiFi)
1. Find your computer's IP address:
   - Open Command Prompt or PowerShell
   - Type: `ipconfig | findstr "IPv4"`
   - Look for: `192.168.1.xxx` (your local IP)

2. On your iPad/phone browser:
   - Go to: `http://YOUR-IP-ADDRESS:9876`
   - Example: `http://192.168.1.100:9876`

3. **Play!** Full touch controls and mobile optimization

### Worldwide Play (Advanced)
For playing from anywhere (even vacation!):
- Set up Tailscale VPN (free for personal use)
- Get worldwide access without port forwarding
- Works from Burundi, Tokyo, or anywhere

## 🔧 Troubleshooting (Simple Fixes)

### "Page won't load"
- **Check**: Is the installer still running?
- **Fix**: Wait for "Installation complete!" message
- **Alternative**: Try `http://127.0.0.1:9876`

### "Games are slow"
- **Check**: Are other programs running?
- **Fix**: Close unnecessary programs
- **Tip**: Use Chrome or Firefox for best performance

### "AI opponents not working"
- **Check**: Are you on the same WiFi?
- **Fix**: For local play, stay on same network
- **Test**: Try a simple game first (Tic-Tac-Toe)

### Mobile/iPad Issues
- **Check**: Are you using the correct IP address?
- **Fix**: Double-check with `ipconfig` command
- **Tip**: Some school/corporate WiFi blocks gaming ports

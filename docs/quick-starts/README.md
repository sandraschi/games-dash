# 🚀 Quick Start Guides

Choose your path based on who you are and what you want to do:

## 🎮 For Gamers (Just Want to Play)
**"I want to play games now!"**

### ⚡ One-Click Setup (2 minutes)
1. Download the latest release
2. Double-click `Install_Games.bat`
3. Open `http://localhost:9876`
4. **Start playing!**

### 🎯 What You'll Get
- 75 games ready to play
- AI opponents for single-player
- Local multiplayer with friends
- Mobile support for iPad/phone

**[→ Gamer's Quick Start](for-gamers.md)** - Complete setup guide

---

## 👨‍💻 For Developers (Want to Contribute)
**"I want to add features or fix bugs"**

### 🔧 Development Setup (10 minutes)
```bash
# 1. Clone the repository
git clone https://github.com/your-org/games-app.git
cd games-app

# 2. Install dependencies
pip install -r requirements.txt
npm install

# 3. Start development servers
.\START_ALL_SERVERS.ps1  # AI engines
python -m http.server 9876  # Web server
```

### 🎯 What You'll Work With
- Modern web technologies (HTML/CSS/JS)
- Python AI backend servers
- Docker containerization
- Automated testing suite

**[→ Developer's Quick Start](for-developers.md)** - Development environment setup

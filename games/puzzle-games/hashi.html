How to Play Hashi

  • Islands are circles with numbers
  • The number indicates how many bridges must connect to that island
  • Bridges can be single or double lines
  • Bridges cannot cross each other
  • All islands must be connected in one network
  • Bridges can only run horizontally or vertically
  • Bridges cannot go through islands

SNIPES

1983 Novell NetWare classic. Destroy snipes and hives. One of the first networked multiplayer games.

Score: 0 Lives: 3 Snipes: 0 Press SPACE to start
Arrow keys: move. W A S D: shoot (up left down right). Combine for diagonal shots. SPACE: sprint.

🛠️ Software Installation Guide

Complete installation guide for the FlowEngineering development stack. All tools needed to build modern AI-assisted applications.

💻 Operating System Requirements

REQUIRED: Windows 11 or macOS Tahoe

❌ Linux doesn't work for FlowEngineering, sorry! 🫤

The FlowEngineering methodology relies on specific AI integrations and development tools that are currently optimized for Windows 11 and macOS Tahoe ecosystems.

⚠️ Installation Order

Install tools in this order: Core Development → AI Tools → Creative Tools → Utilities. Some tools require accounts to be created after installation.

🚀 AI Will Help You From Here!

Once you have Cursor or Antigravity IDE working:

🎯 Just ask the LLM for any further installs, setups, tricks, and shenanigans!

Your AI development partner will guide you through complex configurations, troubleshoot issues, suggest optimal setups, and help you master advanced workflows. The FlowEngineering approach means you're never stuck - your AI assistant becomes your expert development mentor!

🎯 Installation Checklist

Use this checklist to track your setup progress:

  • ☐ Cursor IDE or Antigravity IDE
  • ☐ Claude Desktop (optional but recommended)
  • ☐ Steam + VRChat (for VR testing)
  • ☐ Unity 3D (for 3D development)
  • ☐ Git/GitHub Desktop + GitHub account
  • ☐ Node.js, Python, Docker Desktop
  • ☐ VirtualBox (for virtualization)
  • ☐ Ollama + LM Studio (local AI models)
  • ☐ AI accounts (Claude, Gemini, GitHub Copilot, etc.)
  • ☐ Creative tools (Blender, Obsidian)
  • ☐ Utility tools (WizFile, Hasleo Backup, PowerToys)

💡 Pro Tips

  • Start Small: Install core development tools first, then add AI and creative tools
  • Free Tiers First: Test with free versions before committing to paid subscriptions
  • Create Accounts: Most tools require account creation after installation (especially GitHub)
  • Local AI Setup: Start with Ollama/LM Studio for privacy, then explore API services
  • Virtualization: Use VirtualBox for testing different environments without affecting your main system
  • Stay Updated: Keep tools updated for best AI integration and security
  • Backup Regularly: Use Hasleo or similar tools to backup your development environment
  • PowerToys Boost: Microsoft PowerToys adds productivity features like advanced window management

WebSocket Multiplayer API

Connection Establishment:
const ws = new WebSocket('ws://localhost:8765');

ws.onopen = () => {
console.log('Connected to multiplayer server');
// Send join game message
ws.send(JSON.stringify({
type: 'join_game',
gameId: 'chess_123',
playerId: 'player_456'
}));
};
Message Type Direction Description Payload
WS join_game Client → Server Join multiplayer game {gameId, playerId, gameType}
WS game_state Server → Client Current game state {board, currentPlayer, gameStatus}
WS make_move Client → Server Submit game move {move, playerId, timestamp}
WS move_result Server → Client Move validation result {valid, newState, error?}
WS player_joined Server → Client New player notification {playerId, playerName}
WS game_over Server → Client Game completion {winner, finalScore, stats}

Firebase Integration

Cloud-based multiplayer fallback with real-time database and authentication. Used when local WebSocket connections are not available.

Firebase Configuration:
import { initializeApp } from 'firebase/app';
import { getDatabase, ref, onValue, set } from 'firebase/database';

const firebaseConfig = {
apiKey: process.env.FIREBASE_API_KEY,
authDomain: "games-app.firebaseapp.com",
databaseURL: "https://games-app-default-rtdb.firebaseio.com",
projectId: "games-app",
storageBucket: "games-app.appspot.com",
messagingSenderId: "123456789",
appId: "1:123456789:web:abcdef123456"
};

const app = initializeApp(firebaseConfig);
const database = getDatabase(app);
Real-time Game Sync:
function syncGameState(gameId, localState) {
const gameRef = ref(database, `games/${gameId}`);

// Listen for remote changes
onValue(gameRef, (snapshot) => {
const remoteState = snapshot.val();
if (remoteState.timestamp > localState.timestamp) {
// Apply remote state
updateLocalGame(remoteState);
}
});

// Push local changes
set(gameRef, {
...localState,
timestamp: Date.now()
});
}

Rate Limiting:
// Client-side rate limiting
class RateLimiter {
constructor(maxRequests = 10, windowMs = 60000) {
this.maxRequests = maxRequests;
this.windowMs = windowMs;
this.requests = [];
}

canMakeRequest() {
const now = Date.now();
// Remove old requests
this.requests = this.requests.filter(time => now - time < this.windowMs);

if (this.requests.length >= this.maxRequests) {
return false;
}

this.requests.push(now);
return true;
}
}

Integration Testing

WebSocket Test Client:
const testWebSocketConnection = async () => {
const ws = new WebSocket('ws://localhost:8765');

return new Promise((resolve, reject) => {
ws.onopen = () => {
console.log('✅ WebSocket connected');
ws.send(JSON.stringify({type: 'ping'}));
};

ws.onmessage = (event) => {
const data = JSON.parse(event.data);
if (data.type === 'pong') {
console.log('✅ WebSocket responsive');
ws.close();
resolve(true);
}
};

ws.onerror = (error) => {
console.error('❌ WebSocket error:', error);
reject(error);
};

setTimeout(() => {
ws.close();
reject(new Error('Connection timeout'));
}, 5000);
});
};

Deployment & Scaling

Docker Containerization:
# Dockerfile for backend services
FROM python:3.9-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
EXPOSE 8000

# Health check for container orchestration
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
CMD curl -f http://localhost:8000/health || exit 1
